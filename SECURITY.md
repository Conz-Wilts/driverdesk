# Security policy

DriverDesk runs code that talks to hardware, verifies signatures and sandboxes untrusted logic, so we take reports seriously.

## Reporting a vulnerability

**Do not open a public issue.** Report privately through GitHub's private vulnerability reporting: open the repository's **Security** tab → **Report a vulnerability**.

Please include the affected component (runtime, agent, registry, signing, sandbox, spec parser, lab tooling), a description, reproduction steps, and the impact you expect.

We aim to acknowledge reports within 3 working days and to agree a disclosure timeline with you, normally no longer than 90 days.

## Supported versions

The project is pre-alpha. Only the latest commit on `main` receives fixes.
