# DD-L016: safety block not signed

Severity: **warning**

## What it means

The safety envelope is not signed. Fine locally; the registry will not publish it for a vendor.

## How to fix it

Sign it when publishing (`dd sign`, stage P4).

## Example: the safety block has no signature (warning)

Fixture `spec/fixtures/invalid/41-L016-unsigned-safety.yaml`:
