# DD-L026: unknown UCUM unit

Severity: **error**

## What it means

A unit is not a UCUM code, so conversions cannot be checked.

## How to fix it

Use the suggested UCUM code: `Cel`, `Pa`, `%`, `m/s2`, `mA`, `lx`.
