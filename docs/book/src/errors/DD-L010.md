# DD-L010: unknown spec version

Severity: **error**

## What it means

The `spec:` line names a version this validator does not implement.

## How to fix it

Write `spec: driverdesk/0.1`.

## Example: the spec version is wrong

Fixture `spec/fixtures/invalid/34-L010-unknown-spec-version.yaml`:

```text
DD-L010 (https://driverdesk.dev/errors/DD-L010)

  × unknown spec version `driverdesk/0.1.0`

   ·       ────────┬───────

 4 │ device:
   ╰────
  help: write `spec: driverdesk/0.1`
```
