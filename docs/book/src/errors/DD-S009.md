# DD-S009: other schema violation

Severity: **error**

## What it means

A construct the spec does not allow, such as a YAML tag (`!!str`).

## How to fix it

Write the value plainly; quote it if it must be text.

## Example: a YAML tag is used

Fixture `spec/fixtures/invalid/21-yaml-tag.yaml`:

```text
DD-S009 (https://driverdesk.dev/errors/DD-S009)

  × YAML tags are not supported (`tag:yaml.org,2002:str`)
   ╭─[21-yaml-tag.yaml:6:15]
 5 │   id: example.led-thermo
 6 │   name: !!str LED thermometer
   ·               ───────┬───────
   ·                      ╰── remove the tag
 7 │   vendor: { name: Example Labs, prefix: example }
   ╰────
  help: write the value directly; quote it if it must be a string
```
