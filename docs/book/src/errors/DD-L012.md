# DD-L012: CEL expression does not compile

Severity: **error**

## What it means

An expression is not valid CEL, or calls a function outside the DriverDesk profile.

## How to fix it

CEL has no `|`, `&`, `<<`, `>>`: use `bor`, `band`, `shl`, `shr`. See spec §10.3 for the function list.
