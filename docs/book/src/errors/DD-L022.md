# DD-L022: unknown variable, argument or local in an expression

Severity: **error**

## What it means

An expression uses a name that is not defined at that point.

## How to fix it

Define it earlier with `as:` or `let:`, or declare it in `vars`, `settings` or `instance`.

## Example: an output uses a local that was never defined

Fixture `spec/fixtures/invalid/48-L022-unknown-name.yaml`:

