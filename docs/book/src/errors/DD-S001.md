# DD-S001: YAML syntax error

Severity: **error**

## What it means

The file is not valid YAML, so nothing else can be checked.

## How to fix it

Look at the marked line: unclosed `[`/`{`, a tab used for indentation, or a missing space after `key:`. Use spaces only.

## Example: a flow list is not closed

Fixture `spec/fixtures/invalid/01-syntax-unclosed-bracket.yaml`:

```text
DD-S001 (https://driverdesk.dev/errors/DD-S001)

  × YAML syntax error: invalid indentation
    ╭─[01-syntax-unclosed-bracket.yaml:26:1]
 25 │     - { name: check,   checksum: crc8-smbus, over: [header, length, payload }
 26 │ commands:
    · ┬
    · ╰── here
 27 │   read_temp:
    ╰────
  help: check indentation (spaces only, no tabs) and that every `key:` is followed by a space
```
