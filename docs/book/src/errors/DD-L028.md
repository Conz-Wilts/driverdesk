# DD-L028: integer with a leading zero (octal in YAML 1.1, decimal in 1.2)

Severity: **error**

## What it means

An integer with a leading zero is octal in YAML 1.1 and decimal in YAML 1.2.

## How to fix it

Remove the leading zero, or write octal as `0o17`.
