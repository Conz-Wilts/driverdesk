# DD-S005: value not allowed (enum/const/pattern)

Severity: **error**

## What it means

A value is not one of the allowed words or does not have the required form.

## How to fix it

Use one of the values listed in the help line; names are lower_snake_case, bit ranges are `"H:L"`.

## Example: the match bus is misspelt

Fixture `spec/fixtures/invalid/12-unknown-bus.yaml`:

```text
DD-S005 (https://driverdesk.dev/errors/DD-S005)

  × unknown bus `usbb` in `match[0]`
    ╭─[12-unknown-bus.yaml:11:10]
 10 │ match:
 11 │   - bus: usbb
    ·          ──┬─
    ·            ╰── unknown
 12 │     vid: 0x1209
    ╰────
  help: did you mean `usb`?
```

## Example: a bit range uses a dash instead of a colon

Fixture `spec/fixtures/invalid/15-bad-bit-range.yaml`:

```text
DD-S005 (https://driverdesk.dev/errors/DD-S005)

  × `11-10` is not a valid value for `registers.map.CONFIG.fields.mode.bits`
    ╭─[15-bad-bit-range.yaml:28:23]
 27 │       fields:
 28 │         mode: { bits: "11-10", enum: { continuous: 0, shutdown: 1 } }
    ·                       ───┬───
    ·                          ╰── invalid
 29 │         ready: { bits: "13", access: ro }
    ╰────
  help: bit ranges are `"H:L"` (inclusive, LSB = 0) or a single bit `"N"`, quoted, for bits 0–63
```
