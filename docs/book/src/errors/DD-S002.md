# DD-S002: required field missing

Severity: **error**

## What it means

A field the spec requires is missing, or a list that must have entries is empty.

## How to fix it

Add the field named in the message. The help line names the spec section that describes it.

## Example: device.name is missing

Fixture `spec/fixtures/invalid/03-missing-device-name.yaml`:

```text
DD-S002 (https://driverdesk.dev/errors/DD-S002)

  × missing required field `name` in `device`
   ╭─[03-missing-device-name.yaml:4:1]
 3 │ spec: driverdesk/0.1
 4 │ device:
   · ───┬──
   ·    ╰── add `name:` here
 5 │   id: example.led-thermo
   ╰────
  help: `name` is required (spec §4), for example:
        name: <human-readable name>
```
