# DD-S003: wrong type

Severity: **error**

## What it means

A value has the wrong type, e.g. text where a number is expected.

## How to fix it

Remove quotes around numbers (`vid: 0x1209`, not `"0x1209"`), drop unit suffixes (`timeout_ms: 50`), and use `[ ]` for lists.

## Example: the USB vendor id is quoted, so it is text not a number

Fixture `spec/fixtures/invalid/06-quoted-vid.yaml`:

```text
DD-S003 (https://driverdesk.dev/errors/DD-S003)

  × `match[0].vid` must be an integer, found text
    ╭─[06-quoted-vid.yaml:12:10]
 11 │   - bus: usb
 12 │     vid: "0x1209"
    ·          ────┬───
    ·              ╰── wrong type
 13 │     pid: 0x0001
    ╰────
  help: write an integer
```
