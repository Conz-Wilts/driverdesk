# DD-S004: unknown field (with "did you mean")

Severity: **error**

## What it means

A field name is not part of the spec at this place. Usually a typo.

## How to fix it

Use the suggested name. Vendor-specific data goes in keys starting with `x-`.

## Example: `device` is misspelt

Fixture `spec/fixtures/invalid/09-unknown-top-level-field.yaml`:

```text
DD-S004 (https://driverdesk.dev/errors/DD-S004)

  × unknown field `devcie` at the top level
   ╭─[09-unknown-top-level-field.yaml:4:1]
 3 │ spec: driverdesk/0.1
 4 │ devcie:
   · ───┬──
   ·    ╰── not allowed here
 5 │   id: example.led-thermo
   ╰────
  help: did you mean `device`?
```
