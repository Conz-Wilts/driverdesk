# DD-S007: duplicate key

Severity: **error**

## What it means

The same key appears twice in a map, or a list repeats an entry. YAML silently keeps only one.

## How to fix it

Delete or rename one of them; both locations are marked.

## Example: the same key appears twice in a map

Fixture `spec/fixtures/invalid/20-duplicate-key.yaml`:

```text
DD-S007 (https://driverdesk.dev/errors/DD-S007)

  × duplicate key `timeout_ms`
    ╭─[20-duplicate-key.yaml:33:5]
 31 │       celsius: { cel: "double(raw) / 100.0", unit: Cel }
 32 │     timeout_ms: 50
    ·     ─────┬────
    ·          ╰── first defined here
 33 │     timeout_ms: 60
    ·     ─────┬────
    ·          ╰── duplicate
 34 │     retries: 2
    ╰────
  help: the validator uses the first value and ignores this one (some YAML tools keep the last
        instead); delete the one you do not want
```
