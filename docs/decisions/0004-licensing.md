# 0004. Licensing: Apache-2.0 code, CC-BY-4.0 spec, DCO, trademark for quality

- Status: accepted · Date: 2026-10-10 · Class: one-way · Source: north star §09

## Decision
- All code (including registry and portal): Apache-2.0 (patent grant matters to hardware companies).
- Spec text: CC-BY-4.0 plus a royalty-free patent pledge (drafted in R1, counsel-reviewed).
- Contributions: Developer Certificate of Origin (`Signed-off-by`), no CLA.
- The name and "Verified" badge are trademarks (filing in R1, human action).
- Community descriptions: recommend CC0 or Apache-2.0; publishers choose.
- Runtime crates must not depend on GPL code (enforced by cargo-deny).
