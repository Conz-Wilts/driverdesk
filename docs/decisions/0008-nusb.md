# 0008. USB access through `nusb`

- Status: accepted (provisional) · Date: 2026-10-10 · Class: two-way · Review trigger: any blocking bug in P1/P2 that nusb maintainers cannot resolve within 2 weeks

## Decision
`nusb` (pure Rust, Linux/macOS/Windows, async + blocking, hotplug) for USB. Fallback: `rusb` (libusb) behind the same `UsbBackend` trait.

## Why
No C dependency, maintained (0.2.x, active in 2026), supports all three OSes and hotplug.
